The authorization path

The AI owns the proposal. CIRCUIT owns the decision boundary and evidence.

  1. 01Propose

    An agent submits a structured portfolio action.

  2. 02Project

    CIRCUIT computes the exact post-trade portfolio.

  3. 03Evaluate

    The active mandate returns machine-readable constraints.

  4. 04Authorize

    A passing action receives a short-lived, state-bound approval.

  5. 05Execute

    The X Layer gate rechecks state before capital moves.

  6. 06Prove

    A linked receipt records the decision and chain result.
